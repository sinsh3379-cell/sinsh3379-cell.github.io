# 주택관리사 CBT 문제은행

태블릿·휴대폰에서 바로 풀 수 있는 주택관리사 CBT(모의고사) 모음입니다. 설치 없이 링크만 열면 됩니다.

## 안내

- 메인 주소를 열면 2차 3대법 CBT 화면이 바로 나옵니다.
- 채점·오답노트·📌 핀·형광펜·오늘 푼 문제는 기기 브라우저에 저장되고, **회사 태블릿·집 태블릿·스마트폰끼리 자동으로 맞춰집니다**(무로그인, 상단 작은 ☁️ 표시).
- 문제 화면 위쪽 보기 탭: **📚 전체 · 📌 핀 마킹 · ✗ 틀린 문제 · ⚠ 내가 고른 오답 · 🔢 숫자 전용**
  - 틀릴 때마다 문항에 자동 별표가 붙습니다(★ → ★★ → ★★★).
  - **오답 자동 졸업** — 오답을 한 번 맞히면 1/2, 한 번 더 맞히면 2/2로 오답 목록에서 자동으로 빠집니다. 중간에 다시 틀리면 0/2로 돌아갑니다. 문항 위의 ❌ 틀린 횟수와 ⭐ 별표는 졸업해도 그대로 남습니다.
  - ⚠ 내가 고른 오답 — 처음 틀렸을 때 고른 선지와 실제 정답을 나란히 봅니다.
  - 🔢 숫자 전용 — 핵심 숫자(기간·비율·면적·금액)가 든 지문만 모아 보여 주고, 숫자는 회색 상자로 가립니다(누르면 공개).
- **📖 회독 모드** — 위 보기 탭 줄 오른쪽 버튼을 누르면 그 단원 문제를 정답·선지별 O/X 해설·핵심·조문까지 한 번에 펼쳐 읽습니다. 회독 중에는 **계산문제(소요량·열관류율·환기횟수·조도 개수 등)를 빼고 말문제만** 나옵니다(평소 풀이는 계산문제도 그대로). 선지를 눌러도 채점·오답·형광펜 기록은 바뀌지 않고, 켠 채로 닫으면 다음에 그대로 회독 모드로 열리며 **읽던 문제 자리**로 돌아갑니다. 📖 회독 모드가 있는 곳 — 민법 · 개인용 회계 · 공유용 회계 · 시설개론 · 공동주택관리실무 · 3대법
- 1차 시설개론·재무회계 등 다른 CBT도 같은 주소 아래 페이지로 추가할 수 있습니다.
