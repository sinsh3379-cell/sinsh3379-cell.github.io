## 안내

- 메인 주소를 열면 2차 3대법 CBT 화면이 바로 나옵니다.
- 채점·오답노트·📌 핀·형광펜·오늘 푼 문제는 기기 브라우저에 저장되고, **회사 태블릿·집 태블릿·스마트폰끼리 자동으로 맞춰집니다**(무로그인, 상단 작은 ☁️ 표시).
- 문제 화면 위쪽 보기 탭: **📚 전체 · 📌 핀 마킹 · ✗ 틀린 문제 · ⚠ 내가 고른 오답 · 🔢 숫자 전용**
  - 틀릴 때마다 문항에 자동 별표가 붙습니다(★ → ★★ → ★★★).
  - ⚠ 내가 고른 오답 — 처음 틀렸을 때 고른 선지와 실제 정답을 나란히 봅니다.
  - 🔢 숫자 전용 — 핵심 숫자(기간·비율·면적·금액)가 든 지문만 모아 보여 주고, 숫자는 회색 상자로 가립니다(누르면 공개).
- 1차 시설개론·재무회계 등 다른 CBT도 같은 주소 아래 페이지로 추가할 수 있습니다.
